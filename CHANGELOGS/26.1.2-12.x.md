Changelog BBL Core

# 12.6.1
- Made helper methods static

# 12.6.0
- Ported TagOutputRecipe from Strainers to Core, this is a custom recipe type that allows shaped crafting recipes with a tag output
- Added ShapedTagOutputRecipeProvider for data generation of these recipes
- Added ShapedComponentCopyRecipe this allows for crafting recipes to copy a component from the input recipe to the output result
- Added RecipeProviderHelper provides some helper methods for creating recipe providers

# 12.5.8

# 12.5.7

- Duration tooltip no longer renders behind items and fluids
- Fluid Rendering Utils no longer renders text behind items and fluids

- Hopefully fixed double tooltips showing for holding shift with items that already have a shift tool tip
